# Signal Processing Repository

## Overview
This repository contains basic signal processing experiments and simulations using MATLAB/Octave.  
The main focus is on:
- Digital signal generation
- Modulation and demodulation
- FIR filter design
- Audio signal processing
- Multi-tone signal analysis

The code is written for learning and educational purposes, with simple and clear implementations of core DSP concepts.

---

## Features
- Generate sinusoidal signals (multi-frequency)
- Normalize signals for audio processing
- Band-pass filter design using sinc function
- FIR filtering using convolution (`filter`)
- Audio input/output using WAV files
- Visualization of signals and impulse responses
